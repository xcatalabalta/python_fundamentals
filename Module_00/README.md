# Module 00 - Growing Code

This module contains a small set of beginner-friendly Python exercises themed around a garden. Each exercise introduces a basic programming concept such as printing, user input, arithmetic, conditions, loops, recursion, and function parameters.

## Exercises

- Ex0 - Hello Garden: prints a friendly greeting for the garden.
- Ex1 - Garden Name: asks for a garden name and displays it with a status message.
- Ex2 - Plot Area: prompts for the length and width of a rectangular plot and calculates its area.
- Ex3 - Harvest Total: collects harvest weights for three days and prints the total.
- Ex4 - Plant Age: checks whether a plant is old enough to be harvested.
- Ex5 - Water Reminder: asks how many days it has been since watering and warns if the plants need water.
- Ex6 - Count Harvest: includes an iterative and a recursive version that count the days until harvest.
- Ex7 - Seed Inventory: prints inventory information for seeds using different units such as packets, grams, or area coverage.

## How to use

You can test the exercises with the helper script in this folder by running:

python3 main_2.py

This script lets you run each exercise individually or test them all at once.

After running the tests it is strongly recommended to run the script clean.sh
